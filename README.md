# Penjelasan Program 
Program ini membantu Andi untuk menyimpan dan mengelola data buku. Sehingga Andi dapat melihat, menambahkan, mengubah, dan menghapus data buku. Program ini juga menyediakan beberapa operasi pengelolaan data.

1. Dictionary = Kode ini digunakan untuk menyimpan data buku. Data yang disimpan terdiri dari key dan value
2. while True = Digunakan untuk membuat menu pilihan terus berulang, sehingga ketika selesai memilih satu pilihan, program akan kembali menampilkan pilihan lagi
3. for = menampilkan semua data buku yang ada di dalam dictionary
4. break = untuk menghentikan perulangan while True
